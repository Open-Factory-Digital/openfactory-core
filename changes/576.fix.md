**A breakdown no longer files a card on top of one it did not file.** When a requirement is broken into cards, the product role now says which cards build on which. If a card is not opened (refused by the automatic review, out of time, or failed to file), every card that builds on it is held too. The reply names both: "X was not opened, so I held Y, which builds on it". Asking for the breakdown again opens them in order. The reply now names every card that was not opened, not only the first.
