**Discarding a file from the project's room needs a product admin, however the request reached it.** A caller with no conversation of its own (an API token, the CLI) reaches the project's room whatever it asks for, and could discard the room's files without being on `product.admins`; it is now refused with "a file in the project's room is everybody's — a product admin takes it out." To discard such a file, be listed on the project's `product.admins`, or discard from your own conversation.
