**`openfactory explain` shows where every instruction a ticket's passes receive comes from.** For a checkout, it lists in the order a job inlines them the role prompts, the constraints, each framework guideline with what the project's profile did to it, the operator's and the project's guidelines and the document index, read from the job's own context building so it cannot disagree with what a job receives; `--full` prints each block. The developer guide that teaches it is run by the suite.
