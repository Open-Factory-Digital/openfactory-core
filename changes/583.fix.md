**The deployment's settings file is read the way it was written, and a file that cannot be read says so.** `openfactory preflight` read `.env.compose` with rules of its own. A row edited by hand, such as `PANEL_PORT=8788  # moved` or `export ANTHROPIC_API_KEY=…`, was misread, and the preflight then checked the default port or reported no credential. Every reader of the file now uses the same rules as the CLI. A file that is there but cannot be read, for example root-owned after a `sudo` run, now fails the `env_file` check with the repair. The credential check no longer reports that nothing is set.
