**The shared panel token can no longer invite people.** A caller holding only `OPENFACTORY_PANEL_TOKEN` was treated as a person called "panel", so its invitations went through as if somebody had vouched for them. It is now anonymous all the way to the action layer, and `people_invite` refuses it with "an invitation records who vouched for the person, and nobody did". A named row in `OPENFACTORY_PANEL_TOKENS`, a registered person and an SSO login invite as before.
