**A card is never born in the pickup column, whoever creates it.** Every writer of a new card — the board's own new card, a split's children, the factory's impediment card and `preview propose --as-card`, as well as the product role — first asks where the card would start, and creates nothing where it would be picked up and built with nobody queueing it. On Jira, where a new issue starts is read only when it cannot be a guess: a workflow with several statuses a new issue could start in names the one with the new tracker option `intake_status`, and `openfactory doctor` fails `board_intake` until it does. A declared status or state the tracker's type does not have is refused the same way.
