# The OpenFactory program: method, certification, partners, conformance

**The code is free and the name is not, and this directory is what the name buys.** Anyone may
run, fork and sell the platform. What only the project grants is the right to say that a person,
a company, a build or a hosted service is *OpenFactory-certified* — and a grant like that is worth
exactly as much as the process behind it. These pages are that process.

**Status: version 1.0 of the program, proposed on 2026-09-21 for adoption by the maintainers.**
Fees and counts are proposals for the first year; the [sustainability page](07-sustainability.md)
says who may change them and how. The platform itself is pre-1.0, and every page here defers to
[STATUS.md](../STATUS.md) on what works today.

## In one paragraph

A **client** engages a **partner** (or does it alone on the Light profile). The partner's
**Solution Architect** qualifies and assesses the codebase with the platform's own read-only
tools and writes the design record; the **Implementer** installs the deployment, onboards each
project with `onboard`, proves the box, rehearses, runs the first ticket and a costed pilot, and
hands the **Operator** a runbook. The client's **Product Owner** switches on the product role when
ready; the client's developers, certified **Associates**, write cards and read pull requests. The
partner's desk supports the deployment to a tier of the **standard**, keeps it current and
proven, and re-signs the design record yearly. Every person holds a **credential** for the role
they perform; the partner holds a **tier** counted in those credentials and in the deployments it
can show; a hosted service holds a **conformance** against the hosting standard; and the project
earns from the credentials, the tiers and the conformance, never from the client. When a second
partner of scale exists, the marks and the program move to a neutral holder.

## Who wrote this and who changes it

Written by the project's steward from the platform's own documentation and code, the market's
published programs, and the live deployments the platform has run. Changed by the program
committee ([07](07-sustainability.md) §Governance) through pull requests to this directory, so
that every rule has a diff and a date.
